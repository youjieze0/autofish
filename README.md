# 🎣 DeltaForce-AutoFish (三角洲行动 - 自动钓鱼辅助)

专为 Android 端《三角洲行动》打造的全自动钓鱼辅助工具。
采用**纯视觉颜色特征识别**（红线沉水判定），不读取游戏内存、不修改游戏文件，安全稳定，支持后台全自动循环挂机。

## ✨ 核心特性

- **纯视觉识别**：不依赖水花动画和声音，精准提取放大镜画面下的“红线”色彩特征，红线消失（鱼咬钩）瞬间实现**秒提**。
- **仿人类操作防封**：收杆后内置 10 秒固定延迟，模拟真人操作节奏。
- **独立悬浮窗控制**：内置悬浮窗，支持“暂停/恢复”状态无缝切换，完全不干扰正常游戏。
- **自定义适配**：内置框选 UI，完美适配各种分辨率和屏幕比例的手机/平板。

## 🛠️ 安装与使用指南

### 1. 下载安装
- 直接下载本页面提供的 APK 安装包（例如：`AutoFish.apk`）并安装到手机。

### 2. 赋予必要权限 (非常重要)
安装完成后，首次打开软件，请务必根据提示赋予以下权限，否则工具无法正常运行：
- **无障碍服务**：用于模拟点击钓鱼和放大键。
- **悬浮窗权限**：用于在游戏画面上方显示控制台。
- **屏幕截取权限**：用于实时获取游戏画面以识别红线。
- **存储/文件读写权限**：请去手机系统的“设置 - 应用管理”中找到本软件，**手动开启存储权限**，以便保存你的按键坐标和框选配置。

### 3. 配置流程 (仅首次配置需要)
打开软件后，按照主界面的步骤依次配置：
1. **① 选定钓鱼键**：提前准备一张游戏内带有钓鱼按钮的截图，点击此项上传截图，然后准确框选你的“抛竿/收杆”按钮。
2. **② 选定放大键**：同上，上传带有放大按钮的截图，准确框选“放大镜”按钮。
3. **③ 框选红线区域**：准备一张**已开启放大镜、且红线垂直悬浮（鱼未上钩时）**的清晰截图。上传后，**紧贴着红线的边缘**画一个框。
4. **④ 开启悬浮窗**：当以上三步都显示绿色“✅ 已完成”时，点击开启悬浮窗，随后可切换回游戏。

### 4. 挂机逻辑
在游戏内找到钓鱼点，面对水面，确保画面中出现钓鱼 UI 后，点击悬浮窗的 `▶ 开启检测`。
> **自动化工作流**：
> 1. 等待红线消失 (鱼咬钩)
> 2. 触发秒提 (收杆)
> 3. 延迟 10 秒等待收杆动画结束
> 4. 自动抛竿
> 5. 延迟 1 秒后开启放大镜
> 6. 继续等待下一次红线消失...循环往复。
